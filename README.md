# 🌾 农场增量 (Farm Incremental)

> 一款纯前端的放置类农场经营游戏——种田、养殖、加工、贸易、转生，一切尽在浏览器中。支持 Mod 扩展与内置编辑器。

---

## ✨ 特色

- 🖱️ **纯前端零依赖** — 原生 JavaScript，打开即玩，无需构建
- ⏱️ **放置挂机** — 关闭标签页也能在后台继续运行
- 🌤️ **四季天气** — 春/夏/秋/冬轮替，晴/云/雨/暴风雨影响生长
- 🗺️ **四大区域** — 平原、沙地、黑土平原、黏土山，各有专属土壤
- 🌱 **12 种基础作物** — 小麦、胡萝卜、土豆、番茄、玉米、草莓、南瓜、西瓜、蓝莓、向日葵、葡萄、辣椒
- 🧬 **6 种杂交品种** — 邻田种植特定组合触发基因突变
- 🐄 **4 种动物** — 鸡、牛、羊、猪，好感度系统与繁殖
- 🏭 **7 种加工设施** — 磨坊、面包房、奶酪坊、织布机、熏制坊、酿酒坊、果酱工坊
- 📈 **17 项升级** — 8 基础升级 + 9 研究升级，含科技树前置依赖
- 🏺 **8 件遗物** — 收获时概率发现，提供永久全局加成
- 💎 **宝石祭坛** — 15 种永久加成，成就奖励宝石
- 🔬 **10 项研究** — 科技树解锁新升级，含研究路线图
- 🏆 **33 项成就** — 涵盖收获、财富、动物、杂交、转生、遗物、故事等多个维度
- 📜 **20 段故事碎片** — 老农的旅程随进度逐步解锁
- 🔄 **转生系统** — 重置进度换取农场之星，金币收入永久 +10%/星
- 📦 **动态库存** — 三种展示模式（字典序 / 按种类 / 按模组），清晰浏览所有产物
- 🤝 **旅行商人** — 随机到访，双向贸易
- 🎲 **13 种随机事件** — 天降甘霖、兔子来袭、双倍市价日、神秘商人等
- 📊 **生长速度悬浮窗** — 悬停农田查看各项加成明细
- 🌗 **深浅色主题** — 一键切换
- 💾 **存档导入导出** — JSON 格式，跨设备迁移
- 🔧 **内置模组编辑器** — 图形化开发界面，支持作物/动物/加工/遗物等 7 类数据
- 📦 **Mod 系统** — 首次游玩选择要启用的 Mod，存档绑定 Mod 列表
- 📱 **响应式设计** — 适配桌面和移动端，触控友好

## 🎮 玩法指南

### 基础循环
1. **种植** — 点击空地选择作物，消耗种子
2. **生长** — 作物随时间自动生长，进度条满后点击收获
3. **收获** — 获得产物和少量种子返还
4. **售卖** — 在库存页批量出售作物换取金币
5. **升级** — 购买自动化设施提升效率

### 进阶系统
| 系统 | 说明 |
|------|------|
| **土壤匹配** | 每种作物有偏好土壤，匹配时生长 +50% |
| **季节轮替** | 30 分钟/季，反季节作物生长减半（温室可无视） |
| **杂交培育** | 在相邻田地种植特定组合，概率触发杂交 |
| **动物养殖** | 好感度满后产出翻倍，有概率自动繁殖 |
| **加工链** | 小麦→磨坊→面粉→面包房→面包，价值倍增 |
| **遗物收集** | 收获时概率发现，提供永久全局加成 |
| **宝石祭坛** | 通过成就获取宝石，购买永久加成（保留至转生后） |
| **地域拓展** | 解锁新区域获得更多土地与不同土壤类型 |
| **科技树** | 升级、研究、宝石祭坛各有前置依赖树，子节点不超过 3 个 |
| **研究系统** | 消耗金币与研究点数解锁研究，完成后可购买对应升级 |
| **转生** | 累计金币达标后可转生，获得农场之星并解锁更多土地 |

### 天气系统
| 天气 | 效果 |
|------|------|
| ☀️ 晴天 | 生长 +10% |
| 🌧️ 雨天 | 生长 +30% |
| ⛅ 多云 | 无加成 |
| ⛈️ 暴风雨 | 生长 -40% |

### 科技树概览
三棵科技树均以"无前置"为根节点，每个节点子节点不超过 3 个：

- **升级科技树**：稻草人助手 → 灌溉系统 → 肥料研究 → 温室 → 自动收割机 / 高级洒水器 / 超级肥料 → 无人机群
- **研究科技树**：谷物堆肥 → 轮作制度 / 节水灌溉 → 杂交图谱 / 饲料科学 → 种子精选 / 深耕技术 → 温室优化 / 动物基因 / 收获工艺
- **宝石科技树**：绿手指 → 绿手指进阶 → 丰收赐福 → 丰收赐福 II / 精工巧匠 / 光合作用 ……

- **零构建步骤**：纯原生 JavaScript，无框架、无打包、无外部依赖
- **架构风格**：全局状态对象 `GS` + 渲染函数 + 事件委托
- **数据驱动**：`DataRegistry` 集中管理所有数据，通过 `rebuildBridge()` 同步到全局变量

## 🛠️ 技术细节

### DataRegistry（核心数据层）
所有游戏数据（作物、动物、升级……）通过 `DataRegistry.register(cat, def)` 注册。引擎启动时调用 `rebuildBridge()` 从 DataRegistry 提取数据并重建全局变量（`CROP_DEFS`、`ANIMAL_DEFS` 等）。Mod 通过 `__modId` 标记来源，DataRegistry 根据启用/禁用状态自动过滤。

API：`register` / `all` / `filter` / `override` / `dump` / `remove` / `enableMod` / `disableMod` / `setEnabledMods`

### 游戏循环
- 主循环 `gameLoop()` 每 200ms 执行一次（`setInterval`）
- 后台运行时通过 `document.hidden` 检测，时之沙漏宝石可维持运行速度
- 自动存档每 30 秒写 `localStorage`
- UI 渲染约每 300ms 批量刷新一次

### Mod 系统
- **清单**：`mods/manifest.js` 声明所有可用 Mod
- **加载**：Mod 脚本在 HTML 中静态加载，不动态注入 `<script>`。启动时根据存档中的 `_enabledMods` 列表启用/禁用
- **首次游玩**：弹出选择 UI，玩家勾选要启用的 Mod
- **存档绑定**：存档中记录启用的 Mod ID 列表。更换设备时若 Mod 不匹配则弹出警告
- **数据隔离**：Mod 数据通过 `DataRegistry.register(cat, def, {modId: "xxx"})` 注册，禁用时自动过滤

### 模组编辑器
- 内置图形化编辑器，位于"模组开发"标签页（需开发者模式）
- 支持 7 类数据：作物、杂交、动物、加工设施、遗物、成就、事件
- 每个条目有专属表单，支持动态添加/删除
- 草稿自动保存至 `localStorage`
- 一键导出为 `.js` Mod 文件或导入已有 Mod 进行编辑
- Seasons、Soils 已解除硬编码，模组可自由定义

### 存档
- 格式：JSON，键为 `farm_save`
- 存储于 `localStorage`，其中 `_enabledMods` 字段追踪启用的 Mod
- 支持 JSON 导入/导出，跨设备迁移

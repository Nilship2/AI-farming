## ✨ 特色

### 🎮 核心玩法
- ⏱️ **放置挂机** — 关闭标签页也能在后台继续运行
- 🌤️ **四季天气** — 春/夏/秋/冬轮替，晴/云/雨/暴风雨影响生长
- 🌱 **12 种基础作物** — 小麦、胡萝卜、土豆、番茄、玉米、草莓、南瓜、辣椒、向日葵、蓝莓、葡萄、西瓜
- 🧬 **杂交品种** — 邻田种植可触发基因突变
- 🐄 **动物养殖** — 鸡、牛、羊、猪，好感度系统与繁殖
- 🏭 **加工设施** — 磨坊、面包房、奶酪坊、织布机、熏制坊、酿酒坊、果酱工坊
- 🔄 **转生系统** — 重置进度换取农场之星，金币收入永久 +10%/星

### ⚙️ 深度系统
- 🎲 **概率掉落池** — 作物/加工/动物产出统一为概率池，支持普通/稀有产物
- 🌳 **科技树** — 可视化升级/宝石/研究的依赖关系，支持缩放与拖拽
- 🔬 **研究系统** — 消耗资源解锁永久加成，如谷物堆肥、轮作制度、种子精选
- 🏺 **遗物收集** — 8 件遗物提供永久全局加成
- 💎 **宝石祭坛** — 15 种永久加成，成就奖励宝石
- 🏆 **成就系统** — 30+ 成就涵盖多维度
- 📜 **故事碎片** — 老农日记随进度解锁
- 📖 **图鉴系统** — 作物/动物/杂交/事件/天气/季节，点击查看详情与概率掉落
- 🤝 **旅行商人** — 随机到访，双向贸易
- 🎲 **随机事件** — 天降甘霖、兔子来袭、神秘商人等

### 🧩 Mod 与社区
- 📦 **Mod 社区** — 浏览/下载/点赞/排序/搜索社区 Mod
- 🤖 **AI 开发面板** — 接入 DeepSeek API，用自然语言生成 Mod
- 💾 **多存档槽位** — 独立存档管理
- 🔧 **调试面板** — 三击标题进入，可触发事件/调整数据

### 🎨 体验优化
- 📊 **悬浮提示窗** — 悬停农田查看生长加成明细；悬停种植卡片查看概率掉落；悬停科技树节点查看详情
- 🌗 **深浅色主题** — 一键切换
- 📱 **移动端适配** — 手风琴菜单、长按悬浮提示
- 💾 **存档导入导出** — JSON 格式，跨设备迁移

## 🎮 玩法指南

### 基础循环
1. **种植** — 点击空地选择作物，消耗种子
2. **生长** — 作物随时间自动生长，进度条满后点击收获
3. **收获** — 按概率池产出作物与额外掉落（种子返还等）
4. **售卖** — 在库存页批量出售作物换取金币
5. **升级** — 购买自动化设施提升效率

### 进阶系统
| 系统 | 说明 |
|------|------|
| **概率掉落池** | 收获时对每项产物独立判定的概率，含普通和稀有产物。升级/遗物可提升普通产物数量 |
| **土壤匹配** | 部分作物有偏好土壤，匹配时生长速度 +50% |
| **季节轮替** | 30 分钟/季，反季节作物生长减半（温室可无视） |
| **杂交培育** | 在相邻田地种植特定组合，概率触发杂交 |
| **动物养殖** | 好感度满后切换至高产出概率池，有概率自动繁殖 |
| **加工链** | 小麦→磨坊→面粉→面包房→面包，价值倍增 |
| **科技树** | 图鉴标签页旁，可视化浏览所有升级/宝石/研究的解锁路径 |
| **研究** | 消耗资源完成研究，获得永久效果（种子返还率提升等） |
| **遗物收集** | 收获时概率发现，提供永久全局加成 |
| **宝石祭坛** | 通过成就获取宝石，购买永久加成（保留至转生后） |
| **转生** | 累计金币达标后可转生，获得农场之星并解锁更多土地 |

### 天气系统
| 天气 | 效果 |
|------|------|
| ☀️ 晴天 | 生长 +10% |
| 🌧️ 雨天 | 生长 +30% |
| ⛅ 多云 | 无加成 |
| ⛈️ 暴风雨 | 生长 -40% |

## 🏗️ 项目结构

```
农场增量/
├── index.html                 # 主页面（UI 布局 + 样式）
├── server.js                  # Mod 社区 API 服务器（Node.js + Express + SQLite）
├── db.js                      # SQLite 数据库（sql.js）
├── core/
│   ├── registry.js            # 数据注册中心
│   ├── engine.js              # 核心引擎（产出概率池、图鉴、事件等）
│   ├── engine-v2.js           # 引擎增强（多区域、研究、杂交扩展、种植面板）
│   ├── mod-loader.js          # Mod 加载器
│   ├── community-mod-loader.js # 社区 Mod 加载器
│   ├── mod-editor.js          # Mod 编辑器
│   ├── save-slots.js          # 多存档槽位系统
│   ├── tech-tree.js           # 科技树可视化
│   ├── debug-panel.js         # 调试面板
│   └── patch.js               # UI 增强补丁（悬浮窗、主题、详情弹窗等）
├── data/                      # 数据定义文件（作物/动物/加工/遗物/升级/研究/事件等）
├── mods/                      # 本地 Mod 目录
├── outputs/                   # AI 生成的 Mod 输出
├── deploy-package/            # 生产部署包（含 install.bat / install.ps1）
└── .env                       # 环境变量（DEEPSEEK_KEY 等，部署时自动生成）
```

- **零构建步骤**：纯原生 JavaScript，无框架、无打包、无外部依赖
- **架构风格**：全局状态对象 `GS` + 渲染函数 + 事件委托
- **部署**：将 `deploy-package/` 上传至 Windows Server，双击 `install.bat` 即可

## 🛠️ 技术细节

- 游戏循环：`setInterval(gameLoop, 200)`，后台运行时自动限速防跳帧
- 存档：`localStorage` 自动保存（每 30 秒）+ JSON 导入导出
- UI 渲染：全量重绘 + 事件委托 `data-action`
- 生长速度计算：实时整合升级/天气/遗物/宝石/季节/土壤六大因素
- 概率池：`ensureCropPool` / `rollPool` 统一管理，支持旧存档自动迁移
- 响应式设计：适配桌面和移动端
- Mod API：Node.js 后端，支持上传/下载/搜索/排序/点赞
